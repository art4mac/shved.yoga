# Адмінка на тому самому домені за `/admin`

Адмінка — одна для бота й для сайту, на starlette-admin, за шляхом `/admin` того самого домену, а не на окремому піддомені. Автентифікація — власна таблиця користувачів у БД (не Basic auth і не oauth2-proxy), тобто саме адмінка є джерелом істини для того, хто має доступ.

## Considered Options

- **Окремий хост `admin.…` + oauth2-proxy** — рекомендовано й відкинуто власником продукту на користь простоти одного домену.

## Consequences

Адмінка живе на публічному домені клієнта, тому обовʼязкові `Disallow: /admin` у `robots.txt`, `noindex` у відповідях, обмеження частоти запитів на Traefik і хешовані паролі. Домен також перестає бути суто статичним — див. наслідки в ADR-0002.
